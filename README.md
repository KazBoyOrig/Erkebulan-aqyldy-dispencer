# Автоматты дәрі-дәрмек үлестіргіш

Бұл жоба дәріні белгіленген уақытта қабылдауды еске салатын құрылғының 3D тұжырымдамасын көрсетеді. Дәрі беру уақыты келгенде HTML симуляциясы экранда хабарлама шығарады, дыбыстық белгі береді және таблеткалардың науаға түсуін көрсетеді.

## Жоба файлдары

| Файл | Мазмұны |
| --- | --- |
| [index.html](index.html) | Айналдырылатын 3D көрініс, бөлшектердің қазақша сипаттамасы және дәрі беру симуляциясы. |
| [smart-pill-dispenser.glb](smart-pill-dispenser.glb) | Blender сияқты 3D редакторға импорттауға болатын түпнұсқа модель. |
| [README.md](README.md) | Жобаның сипаттамасы және пайдалану нұсқаулығы. |

## HTML-нұсқаны ашу

1. `index.html` файлын компьютерге сақтап, браузерде ашыңыз. Модель HTML файлының ішіне енгізілген, сондықтан бөлек сервер, интернет немесе қосымша кітапхана қажет емес.
2. Модельді тінтуірмен сүйреп немесе **←** және **→** түймелері арқылы айналдырыңыз. Сенсорлық экранда модельді саусақпен сүйреуге болады.
3. **+** және **−** түймелері көріністі үлкейтеді немесе кішірейтеді. **Бастапқы көрініс** түймесі бұрыш пен масштабты қалпына келтіреді.
4. **Модельдің бөлшектері** тізімінен бір бөлшекті таңдаңыз. Оның орны модельде нөмірмен белгіленеді, ал жанында сипаттамасы ашылады.

## Дәрі беру симуляциясы

### Бірден сынау

1. **Қазір сынау** түймесін басыңыз.
2. Экранда «Дәрі беріліп жатыр» күйі көрсетіліп, таблеткалар науаға түседі. Браузер дыбыс ойнатуға рұқсат берсе, үш қысқа белгі естіледі.
3. Таблеткалар науаға жеткенде **Таблетканы алдым** түймесі іске қосылады. Оны басқанда таблеткалар көріністен алынады және симуляцияны қайта бастауға болады.

### Уақыт белгілеу

1. **Еске салу уақыты** өрісінде сағат пен минутты таңдаңыз.
2. **Уақытты белгілеу** түймесін басыңыз. Таңдалған минут бүгін өтіп кетсе, еске салу ертеңге қойылады. Ағымдағы минут таңдалса, симуляция бірден іске қосылады.
3. Белгіленген уақытта науа бос болса, таблеткалар түседі. Науада алдыңғы таблеткалар тұрса, экран оны хабарлайды және қосымша таблеткалар берілмейді.
4. Жоспарды алып тастау үшін **Еске салуды өшіру** түймесін басыңыз.

Еске салу бір рет іске қосылады. Уақыт браузер ашылған құрылғының жергілікті сағатына сүйенеді. Бет жабылса немесе қайта жүктелсе, белгіленген уақыт өшеді.

## Модельді Blender бағдарламасында ашу

Blender мәзірінен **File → Import → glTF 2.0 (.glb/.gltf)** тармағын таңдап, `smart-pill-dispenser.glb` файлын импорттаңыз. GLB файлы құрылғының сыртқы пішінін, материалдарын және экрандағы жазуды қамтиды. Таблеткалардың қозғалысы, еске салу және дыбыс HTML-нұсқада іске асырылады.

## Жобаның ауқымы

Бұл оқу жобасы құрылғының сыртқы құрылысын және дәрі беру барысын көрсетуге арналған. Ішкі үлестіру механизмі мен электроника 3D модельге енгізілмеген. HTML симуляциясы нақты құрылғыны басқармайды.
