# Автоматты дәрі-дәрмек үлестіргіш

Бұл 3D модель дәріні белгіленген уақытта қабылдауды еске салатын құрылғының тұжырымдамасын көрсетеді. Экранда «08:00» және «Дәрі уақыты» деген хабарлама бейнеленген. Динамик дыбыстық ескертуге, ал алдыңғы науа таблеткаларды алуға арналған.

## Құрылғының бөліктері

- Дәрі салуға арналған жоғарғы қақпақ
- Уақыт пен хабарламаны көрсететін экран
- Динамик торы мен басқару батырмасы
- Таблетка шығатын саңылау және қабылдау науасы

## Модельді ашу

[smart-pill-dispenser.glb](smart-pill-dispenser.glb) файлын Blender бағдарламасына **File → Import → glTF 2.0** мәзірі арқылы импорттауға болады. Модель статикалық, дәріні үлестіру механизмі мен электрондық басқару жүйесі модельденбеген.
